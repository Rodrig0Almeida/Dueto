URL de Sincronização
Cole aqui a URL do seu Google Apps Script. Após guardar, bloqueie para evitar apagar acidentalmente. Toque no indicador de status no topo para sincronizar manualmente.
🧪 Versão de teste
Abre o index2.html só nesta sessão para testar. Ao reiniciar o app, volta ao index.html.
Modo Dev ativo
🔒 Encriptação dos dados sincronizados
Encriptar antes de enviar à nuvem
Cifra o JSON (AES-GCM 256 bits) antes de gravar na planilha. Quem tiver acesso à célula só vê texto ilegível — só decifra com a senha certa. Feature de teste de segurança.
Desbloquear com digital / Face ID
Guarda a senha protegida pela biometria deste aparelho, para não precisar de digitá-la sempre. A senha continua a ser a chave real — a biometria só desbloqueia o acesso a ela localmente.
Pedir confirmação a cada sincronização
Se ativado, o app sempre pede senha ou biometria antes de decifrar, mesmo já sabendo a senha. Se desativado, decifra automaticamente em segundo plano usando a senha já guardada neste aparelho.
📋 Log de sincronização
Últimos eventos de sincronização (sucesso, erro, tempo esgotado) — útil pra perceber se um problema é do app, da rede, ou da planilha estar lenta.
